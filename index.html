Hospital Formulary

บันทึกเฉพาะการตั้งค่าขนาดยาในเบราว์เซอร์นี้ ไม่บันทึกข้อมูลผู้ป่วย

ต้นแบบรองรับขนาดยาได้สูงสุด 5 ชนิดที่เลือกพร้อมกัน เพื่อคุมประสิทธิภาพการค้นหา

1 · Current Dose

ทราบยอดรวมแล้ว กรอกตรงนี้ได้เลย
ไม่ทราบ Weekly Dose? คำนวณจากจำนวนเม็ด

เลือกวันก่อน แล้วเลือกขนาดเม็ดและจำนวนเม็ด จากนั้นกด Add หรือ Replace

รวมวันที่กรอก 0 mg

2 · Allowed Tablets

ทุกขนาดใน Formulary จะถูกเลือกเป็นค่าเริ่มต้น โปรดเอาเครื่องหมายถูกออกสำหรับขนาดที่ผู้ป่วยใช้ไม่ได้

สำหรับผู้ป่วยที่แพ้สี/ส่วนประกอบ: ตรวจสอบผลิตภัณฑ์จริงด้วยตนเอง เนื่องจากต้นแบบนี้แยกเฉพาะขนาดยา ไม่แยกผู้ผลิต

3 · Adjust Dose

การพิมพ์ขนาดยาเองจะล้างการเลือกปุ่มลัด
กรอก Current Dose เพื่อเริ่ม

4 · Search Rules

สูตรใหม่: สูงสุด 3 เม็ด/วัน · ขนาดยารายวันสูงสุด 2 ขนาด · ใช้ได้เฉพาะเต็มเม็ดและครึ่งเม็ด · มีวันเว้นยาได้

เรียงตามความใกล้ Target → จำนวนวันเว้นยา → จำนวนระดับขนาดยารายวัน → จำนวนขนาดเม็ดสูงสุดต่อวัน → จำนวนวันที่ผสมขนาดเม็ด → วันหักครึ่งเม็ด → Daily Gap → จำนวนขนาดเม็ดทั้งสัปดาห์ → จำนวนเม็ดทั้งสัปดาห์
